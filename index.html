Tool Pocket Generator V68

V68: V25 physical-grid/outline workflow with the proven V30 independent FR1 + FR2 function. Entered Length × Width defines the master rectangle. Photo detection reads the metric ruler ticks on the uploaded photo to measure the tool only, then places that measured outline inside the master rectangle without changing the entered dimensions. Point editing, finger relief, geometry check and STL workflow are retained.

3. Grid sheet

Use the grid as a visual measuring aid. A physical reference grid visible in the uploaded photo can also be used to estimate the tool dimensions and reset the master Length × Width. The on-screen photo grid is only a visual overlay and is not used for measurement.

For measurement, the uploaded photo must actually show the physical reference grid. The overlay is visual only.

4. Photo / picture import

Import a tool photo. V25 analyses the image for a tool-shaped foreground silhouette, suppresses thin/repetitive background-grid structure, and converts the detected outline into editable points. The photo is a reference. If a physical reference grid is visible, you can use it to calculate and reset the master Length × Width; you can then manually correct those values if required.

Use the physical-grid button to calculate/reset master dimensions from the uploaded photo.

5. Draw / edit profile

The orange rectangle is the entered Length × Width reference frame. Draw the actual tool shape; it does not have to be drawn to screen scale. Points can be dragged. Use Add point, delete a point or delete a range, then reconnect automatically. Each segment can independently be Straight or Curved.

Undo: Undo reverses only your edits, newest first. The generated/imported outline is the baseline and is never removed by Undo.
Tip: touching the orange reference-frame border does not add a point. Point editing is explicit: drag an existing point to move it, or use Add point to insert one. A normal tap on an existing point selects it for dragging rather than adding another point.

Finger Relief Access

Finger reliefs are optional. You can use none, one, or two. Each relief is positioned independently by tapping the required place on the profile edge. FR1 and FR2 are the two independent relief locations.

6. Close profile & scale

Final lock. Use this only after the numbered outline and any finger relief are correct.

7. Engineering geometry check

The check is performed after scaling and curve sampling, before STL export. It checks the profile and cleared profile for self-intersection, envelope limits and finger-relief placement.

8. Saved Profiles — JSON

Use these buttons to save or restore the current tool profile. An existing profile JSON can be imported here. JSON is the reusable profile file; it is not the STL used for printing.

9. STL test export

Exports the positive pocket-cut volume used in the tray workflow. The tool profile becomes the cut boundary after clearance, and enabled finger reliefs extend the cutter to their configured depth.
